URL Shortener Service

This project is a URL Shortener Service that converts long URLs into short, It's built using the MERN stack (MongoDB, Express.js, React, Node.js), easy-to-share links. It includes a REST API (built with Node.js + Express + MongoDB) to create, manage, and track short URLs. The API handles all core operations, while the frontend (if included) offers a simple UI to submit and view links. Perfect for learning backend-focuses MERN stack development.

Blogify

Blogify is a simple and modern blogging website where users can share short, informative posts like quick tech tips or learning notes. It's built using the MERN stack (MongoDB, Express.js, React, Node.js), with a clean and responsive design using HTML and CSS. To improve performance, it uses Redis for caching frequently accessed data. The project follows the MVC architecture, keeping the code well-structured and maintainable. Everything runs smoothly in Docker containers, managed with a single docker-compose.yaml file — this makes it easy to set up, test, and deploy the full application with just one command.

Anime Fusion

The project is built with HTML, CSS, JavaScript, Express.js, and EJS templates, and follows a secure login system using JWT authentication with cookies. It features user registration, profile updates, and protected routes using middleware. The anime search result is rendered dynamically based on user input. Everything is organized using an MVC-like pattern, and the UI is responsive and user-friendly.

Password generator

The password generator program is written in Python and creates strong, customizable passwords. It uses lists of alphabets, capital letters, numbers, and special characters to generate passwords based on user-defined length and complexity. Users can choose between "easy," "normal," and "hard" difficulty levels, each with different proportions of character types. The program ensures that the generated password meets the length and complexity requirements by filling in any remaining characters. Finally, it shuffles the characters to create a secure password and prints the result.

Coffee Machine
